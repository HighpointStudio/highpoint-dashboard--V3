# Highpoint Studio Dashboard V2

Nowoczesny i elastyczny panel administracyjny stworzony dla zarządzania społecznościami Roblox oraz połączonymi serwerami Discord.

## 📁 Struktura Projektu

- `index.html` - Główny plik interfejsu (HTML5)
- `styles.css` - Stylowanie aplikacji w motywie Dark / Premium
- `app.js` - Logika interfejsu, przełączanie serwerów oraz obsługa wykresów
- `package.json` - Plik uruchomieniowy pod hosting (Render, Vercel, Netlify)

## 🚀 Jak uruchomić lokalnie?

1. Otwórz plik `index.html` bezpośrednio w dowolnej przeglądarce internetowej.
2. Lub uruchom lokalny serwer w terminalu:
   ```bash
   npx serve .
   ```

## ☁️ Wdrożenie na Render / GitHub

1. Wrzuć zawartość rozpakowanego folderu do swojego repozytorium na GitHubie.
2. W serwisie **Render.com** utwórz nową usługę **Static Site**.
3. Ustaw `Publish Directory` na `.` (kropka).
